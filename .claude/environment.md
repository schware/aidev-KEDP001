# 개발 환경

- 개발: dell-debian(`/srv/projects/aidev-kedp001`). Windows에서는 문서만 다룬다.
- 도구: Go, Rust(`CARGO_BUILD_JOBS=2`), Node(nvm), Docker, gh, gitleaks
- 메모리가 작으므로 무거운 작업(Rust 빌드, Docker 빌드 등)을 동시에 돌리지 않는다.
- 도구 설치는 안내만 하고, 설치는 사람이 한다.
- 조사 샘플 저장 폴더: `samples/repository/` (git에 올리지 않는다). `samples/`의 제공처 폴더에는 소유자가 고른 대표 샘플만 둔다.
