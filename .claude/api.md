# API 키 규칙

- 키는 `.env`에서만 읽는다: `ECOS_API_KEY`, `KOSIS_API_KEY`, `DATA_GO_KR_API_KEY`
- 키 값을 화면, 로그, 결과 보고, commit 메시지, 문서, 샘플 파일에 쓰지 않는다.
- `.env` 내용을 출력하지 않는다. (`cat .env` 금지)
- 요청 주소를 기록하거나 출력할 때는 키 자리를 `***`로 가린다.
- 셸에서 API를 부를 때는 키를 명령에 직접 쓰지 않고 환경 변수로 넘긴다. 요청 주소가 그대로 찍히는 옵션(예: `curl -v`)은 쓰지 않는다.
- commit 전 검사(hook)에 걸리면 `--no-verify`로 우회하지 않고 보고한다.
- 키가 노출된 것 같으면 바로 보고한다. 키 재발급은 소유자가 한다.
- Agent는 API를 직접 부르지 않는다. 샘플이 필요하면 샘플 수집 도구 명령을 적어 소유자에게 요청한다.
