# 데이터 제공처를 ECOS와 KOSIS로 제한

## 검토한 대안

- ECOS와 KOSIS만 사용
<<<<<<< Updated upstream
- 국내외 다른 무료 제공처도 함께 사용

## 결정 이유

제공처가 두 곳이면 이용조건, API 구조, 장애 대응과 데이터 검증 범위를 관리하기 쉽다.

## 영향

초기 지표는 두 제공처에서 확인 가능한 국내 공식 통계로 한정된다.
=======
- ECOS, KOSIS, 공공데이터포털
- ECOS, KOSIS, KRX Open API
- ECOS, KOSIS, 증권사 API

### MVP 범위

ECOS

- 기준금리
- 소비자물가지수
- GDP
- 국민소득
- 외환보유액
- 주식시장
- 채권시장

KOSIS

- 고용률
- 출생아수
- 총인구
- 전산업 사업체 수

공공데이터포털

- KODEX 200
- KODEX 레버리지
- KODEX 인버스

### 향후 확장 원칙

MVP에서는 위 3개 제공처만 사용한다.

새로운 데이터 제공처를 추가할 경우에는
새로운 결정 기록(Decision Record)을 작성하여 검토 후 반영한다.

- 출처가 명확함
