# 데이터 제공처를 ECOS, KOSIS, 공공데이터포털로 제한

## 결론

MVP 데이터 제공처를 다음 3개로 제한한다.

- 한국은행 ECOS
- KOSIS
- 공공데이터포털

유료 데이터, 증권사 API, 웹 스크래핑은 사용하지 않는다.

## 배경

초기 범위를 통제하고 공식·무상 데이터만 사용하기 위한 기준이 필요하다.

1단계에서는 경제지표와 대표 시장지표를 함께 제공한다.

## 검토한 대안

- ECOS와 KOSIS만 사용
- ECOS, KOSIS, 공공데이터포털
- ECOS, KOSIS, KRX Open API
- ECOS, KOSIS, 증권사 API

### MVP 범위

ECOS

- 기준금리
- 소비자물가지수
- GDP
- 국민소득
- 외환보유액
- 주식시장
- 채권시장

KOSIS

- 고용률
- 출생아수
- 총인구
- 전산업 사업체 수

공공데이터포털

- KODEX 200
- KODEX 레버리지
- KODEX 인버스

### 향후 확장 원칙

MVP에서는 위 3개 제공처만 사용한다.

새로운 데이터 제공처를 추가할 경우에는
새로운 결정 기록(Decision Record)을 작성하여 검토 후 반영한다.

## 결정 이유

- 공식 기관 데이터 사용
- 무료 사용 가능
- 장기 운영 가능
- API 접근 가능
- 출처가 명확함

## 영향

- API Key 3개 관리
- Go 수집 대상 증가
- Rust 처리 대상 증가
- Dashboard 지표 구성 가능

## 후속 작업

- ECOS Key 관리
- KOSIS Key 관리
- 공공데이터포털 Key 관리
- 이용약관 및 출처표기 확인
