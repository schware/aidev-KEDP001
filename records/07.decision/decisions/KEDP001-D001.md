# 데이터 제공처를 ECOS와 KOSIS로 제한

## 결론

MVP 데이터 제공처를 한국은행 ECOS와 KOSIS로 제한하고 유료 데이터와 웹 스크래핑을 제외한다.

## 배경

초기 범위를 통제하고 공식·무상 데이터만 사용하기 위한 기준이 필요하다.

## 검토한 대안

- ECOS와 KOSIS만 사용
- 국내외 다른 무료 제공처도 함께 사용
- 유료 데이터까지 포함

## 결정 이유

제공처가 두 곳이면 이용조건, API 구조, 장애 대응과 데이터 검증 범위를 관리하기 쉽다.

## 영향

초기 지표는 두 제공처에서 확인 가능한 국내 공식 통계로 한정된다.

## 미해결 질문

- 프로젝트 소유자 검토 후 `decided` 전환 여부를 확정한다.
