# 데이터 제공처를 ECOS, KOSIS, 공공데이터포털로 제한

## 결론

MVP 데이터 제공처를 한국은행 ECOS, KOSIS, 공공데이터포털(금융위원회_증권상품시세정보)로 제한한다. 유료 데이터, 증권사 API, 웹 스크래핑은 제외한다.

## 배경

초기 범위를 통제하고 공식·무상 데이터만 사용하기 위한 기준이 필요하다. 2026-10-22에 대표 주가지수와 KODEX ETF를 1단계에 넣기로 했는데, ETF 시세는 ECOS·KOSIS에 없다.

## 검토한 대안

- ECOS와 KOSIS만 사용 (지수만)
- ECOS, KOSIS + 공공데이터포털
- ECOS, KOSIS + KRX Open API
- ECOS, KOSIS + 증권사 API (예: 한국투자증권)

## 결정 이유

공공데이터포털은 정부 포털의 무상 공식 데이터다. KRX Open API는 분야별 승인과 이용 조건을 확인하지 못했다. 증권사 API는 계좌가 필요하고, 공개 서비스에 다시 보여주는 것이 약관으로 막힐 수 있으며, 공식 통계기관이 아니다.

## 영향

가입과 키가 3개가 된다. Go 수집 대상과 Rust 분석 대상이 늘어난다.

## 미해결 질문

- 공공데이터포털 이용허락범위(공개 서비스 사용, 출처 표시)
- 프로젝트 소유자 검토 후 `decided` 전환 여부
