# AI Agent 역할을 다섯 영역으로 분리

## 결론

Common Specification, TypeScript, Go, Rust, Database 역할의 AI Agent를 분리하여 운영한다.

## 배경

여러 기술 영역을 한 Agent가 동시에 변경하면 책임 경계와 구현 맥락이 섞일 수 있다.

## 검토한 대안

- 단일 Agent 사용
- 기술 Agent 4개
- Common 지원을 포함한 Agent 5개

## 결정 이유

Common Agent가 사용자의 설계 정리와 작업 분해를 지원하고, 기술 Agent는 담당 영역 구현에 집중한다.

## 영향

Agent 역할은 분리되지만 최종 설계, 결정, 병합은 프로젝트 소유자가 담당한다.
