# 개발 환경

## 결론

개발은 Linux 개발 서버에서, 실행(배포)은 별도 Linux 실행 서버에서 한다. Windows는 문서 작업과 화면(원격 편집기) 역할만 한다. 개발 도구는 개발 서버에 직접 설치해서 쓰고, 전체 흐름 테스트와 배포는 Docker로 한다. 버전은 `go.mod`, `rust-toolchain.toml`, `.nvmrc`로 고정한다.

## 배경

코드, 빌드, 테스트, Docker가 한곳에 있어야 Agent가 작업 결과를 직접 확인할 수 있다. 개발 서버의 메모리가 작아서 무거운 작업을 나눠야 한다.

## 검토한 대안

- 개발 위치: Windows / Linux
- 도구: 직접 설치만 / Docker 안에서만 / 섞어 쓰기

## 결정 이유

직접 설치하면 명령이 빠르고 편집기 자동완성이 잘 동작한다. Docker로는 "내 서버에서만 되는" 문제를 잡는다.

## 영향

개발 서버에 Go, Rust, Node, gRPC 도구, gh, gitleaks를 설치한다. 설치는 Agent가 안내하고 사람이 한다.
