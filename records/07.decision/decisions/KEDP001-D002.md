# TypeScript, Go, Rust와 SQL을 사용

## 결론

TypeScript는 웹, Go는 외부 API와 서비스 API, Rust는 데이터 처리, SQL은 PostgreSQL 저장과 조회에 사용한다.

## 배경

AI Agent를 기술 영역별로 분리하면서 각 언어의 책임 경계를 정할 필요가 있다.

## 검토한 대안

- TypeScript와 Go만 사용
- TypeScript, Go, Rust와 SQL 사용
- 단일 언어로 통합

## 결정 이유

화면, 수집·서비스, 데이터 처리와 저장 책임을 구분하되 실제 API 조사 전 세부 연결 방식은 고정하지 않는다.

## 영향

네 기술 영역의 AI Agent가 분리되어 작업한다. Rust의 실제 처리 범위는 응답 조사 이후 구체화한다.
