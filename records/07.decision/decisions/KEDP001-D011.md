# GitHub 저장소는 비공개로 시작

## 결론

저장소는 비공개(Private) + 무료로 시작한다. 나중에 공개로 바꿀 수 있다.

## 배경

실제 API 키가 3개 있고, 초기 단계라 내부 문서가 많다.

## 검토한 대안

- 비공개 + 무료
- 비공개 + 유료 (제외)
- 공개 + 무료

## 결정 이유

공개로 바꾸는 것은 언제든 가능하지만, 공개했다가 되돌려도 이미 복사된 것은 막을 수 없다.

## 영향

무료 비공개 저장소에서는 main 보호 설정을 강제할 수 없다. "main은 PR로만", "자동 검사 실패면 merge하지 않음"은 약속과 Agent 규칙으로 지킨다.

공개로 바꿀 때는 기록 전체 gitleaks 검사 → 문서 점검 → 샘플 조건 확인 → 전환 → main 보호 설정 순서로 한다.
