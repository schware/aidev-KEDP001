# 한 저장소와 폴더 구조

## 결론

TypeScript·Go·Rust·SQL을 한 저장소(`aidev-KEDP001`)에 둔다. 코드 폴더는 `f-ts-end/`, `b-go-end/`, `b-rust-processor/`, `b-sql-db/`, `b-proto/`로 한다. 맨 위에는 `README.md`, `project.yaml`만 두고, Agent 규칙은 `.claude/`, 안내서와 참고 자료는 `docs/`에 둔다.

## 배경

Go↔TypeScript(REST), Go↔Rust(gRPC), Go·Rust↔DB(스키마) 세 곳이 서로 맞물린다.

## 검토한 대안

- 저장소: 언어별 분리 / 한 저장소
- 폴더 이름: 하는 일(`web/`, `server/`) / 언어(`go/`, `rust/`) / `frontend/`·`backend/` / 위치+언어+역할(`b-go-end/` 등)

## 결정 이유

맞물리는 변경을 commit 하나로 함께 처리하고, 저장소 간 버전 맞추기를 없앤다. 폴더 이름은 `f-`/`b-`로 위치를 보여주고, `_` 대신 `-`를 써서 Docker 서비스 이름과 같게 한다.

## 영향

Agent 경계는 저장소가 아니라 폴더 규칙(`.claude/CLAUDE.md`)으로 지킨다.
