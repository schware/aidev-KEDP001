# 세부 기술 선택

## 결론

| 영역 | 선택 |
| --- | --- |
| 화면 | React + Vite (TypeScript) |
| 화면 꾸미기 | Tailwind CSS |
| 차트 | Apache ECharts |
| Go 수집·API | Go 기본 기능(net/http) |
| Rust gRPC 서버 | tonic |
| DB | PostgreSQL (KEDP001-D002) |

## 배경

KEDP001-D002에서 언어는 정했지만, 각 언어 안에서 쓸 도구는 정하지 않았다. 정하지 않으면 Agent가 대신 고르게 된다.

## 검토한 대안

- 화면: React / Vue / Svelte / Next.js
- 차트: Apache ECharts / Recharts / Chart.js
- 꾸미기: Tailwind CSS / 일반 CSS
- Go: net/http / Gin / Echo

## 결정 이유

- React + Vite: 널리 쓰여 자료가 많고 Agent가 잘 다룬다.
- Apache ECharts: 시계열 차트에 강하다.
- Tailwind CSS: 빠르게 정돈된 화면을 만든다.
- net/http: 조회 API 정도는 추가 도구 없이 충분하다.
- tonic: Rust gRPC의 사실상 표준이다.

## 영향

`docs/sunmoon/KEDP 기술 스택 및 개발 원칙 결정서.md`의 선택을 이 결정으로 확정한다.
