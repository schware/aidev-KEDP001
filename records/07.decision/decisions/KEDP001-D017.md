# MVP 범위: 조회만, 비교와 AI는 2차

## 결론

MVP는 수집 → 저장 → 조회까지만 한다.

- 사용자 화면: 대시보드, 지표 상세
- 관리자 화면: Dashboard 관리, API 관리 (KEDP001-D018)
- 처음 보이는 지표: 기준금리, 고용률, 총인구, CPI, GDP, 출생아 수, 외환보유액, KODEX 200, KODEX 레버리지, KODEX 인버스 (10개)
- 그 밖의 지표(KOSPI, KOSPI200, 전산업 사업체 수, 채권, 국민소득 등)는 관리자 화면의 지표 추가 기능으로 넣는다.

2차 이후로 미루는 것:

- 지표 비교
- AI 분석, AI Agent, 챗봇
- Claude API를 이용한 질문·수집·정리
- 검색, 추천, 상관관계 분석, 예측

## 배경

v0.1 README의 목적에는 "조회하고 비교"가 있었다. 비교를 제대로 하려면 분석이 필요하고, 분석에는 AI Agent와 큰 작업이 필요하다.

## 검토한 대안

- 조회와 비교를 MVP에 포함
- 조회만 MVP, 비교와 AI는 2차

## 결정 이유

MVP를 단순하게 끝낸다. AI 활용은 다른 곳에서 하고 있는 AI 연습이 마무리된 뒤 도전한다. 일부 지표를 처음 화면에서 뺀 것은 지표 추가 기능을 시험하기 위해서다.

## 영향

README 목적에서 "비교"를 뺀다. KEDP001-D001의 MVP 범위 목록 중 처음 화면에 없는 지표는 관리자 화면으로 추가한다. 화면 명세는 `specification/50.web/README.md`를 따른다.
