# 개발 순서: Go와 Rust(API)를 먼저, TypeScript 화면은 나중에

## 결론

기준금리를 첫 대상으로 Go 수집 → Rust 검증 → DB 저장 → Go 조회 API까지 먼저 만든다. API가 마무리되면 TypeScript 화면을 만든다.

## 배경

화면을 먼저 만들지(샘플 데이터 사용), 데이터 흐름을 먼저 만들지 정해야 첫 작업을 시작할 수 있다.

## 검토한 대안

- 순서대로: Go·Rust·DB·API를 먼저, 화면은 나중
- 화면 먼저: 샘플 데이터로 화면을 만든 뒤 API로 교체

## 결정 이유

API가 정해지면 화면이 받을 데이터 모양이 확정되어 TypeScript 작업이 더 쉽게 정리된다.

## 영향

화면은 API 완성 뒤에 볼 수 있다.
