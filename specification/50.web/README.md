# 1. 설계 원칙

## 사용자

사용자는 경제지표를 본다. 할 수 있는 것은 두 가지뿐이다.

- 현재 경제지표 확인
- 지표 상세 보기

검색 기능은 제공하지 않는다. 경제지표 수가 적어 첫 화면에서 모두 확인할 수 있게 설계한다.

## 관리자

관리자는 데이터와 화면 구성을 관리한다. 할 수 있는 것은 다음뿐이다.

- 메인 화면에 보일 지표와 순서
- 지표 설정 (추가, 수집 주기, 차트 기간, 관련 지표, 표시 형식)
- 수집 시간 설정
- API 연결 상태 확인 (키는 다루지 않는다)

관리자 설정은 DB에 저장한다.

## 관리자 접근

관리자 메뉴는 사용자 화면에 노출하지 않는다. 아래 3개 조건을 모두 만족해야 들어갈 수 있다.

- 지정 URL (`/admin`)
- 허용 IP
- 관리자 인증: 계정 + 비밀번호. 서버의 파일 하나로 관리한다. MVP에서는 더 발전시키지 않는다.

허용 IP, 계정, 비밀번호 같은 실제 값은 저장소에 쓰지 않는다.

# 2. 사용자 메인 화면

## 목적

현재 수집된 주요 경제지표를 한눈에 확인한다. 카드를 누르면 상세 화면으로 이동한다.

## 화면 구조

```text
+------------------------------------------------------------------+
| KEDP                                                             |
| Korea Economic Data Platform                                     |
+------------------------------------------------------------------+

                    대한민국 주요 경제지표

+------------------+  +------------------+  +------------------+
| 기준금리         |  | 고용률           |  | 총인구           |
|   3.00%          |  |   62.8%          |  |  51,700,000      |
| 상세보기 >       |  | 상세보기 >       |  | 상세보기 >       |
+------------------+  +------------------+  +------------------+

+------------------+  +------------------+  +------------------+
| CPI              |  | GDP              |  | 출생아수         |
| 114.3            |  | 최신값           |  | 최신값           |
| 상세보기 >       |  | 상세보기 >       |  | 상세보기 >       |
+------------------+  +------------------+  +------------------+

+------------------+  +------------------+  +------------------+
| 외환보유액       |  | KODEX200         |  | KODEX 레버리지   |
| 최신값           |  | 최신값           |  | 최신값           |
| 상세보기 >       |  | 상세보기 >       |  | 상세보기 >       |
+------------------+  +------------------+  +------------------+

+------------------+
| KODEX 인버스     |
| 최신값           |
| 상세보기 >       |
+------------------+
```

> 카드의 숫자는 화면 모양을 보여주기 위한 예시값이다. 실제 수집값이 아니다.

## 처음 보이는 지표

위 10개로 시작한다. KOSPI, KOSPI200, 전산업 사업체 수, 채권, 국민소득 등은 처음 화면에 넣지 않고, **관리자 화면의 지표 추가 기능으로 넣는다.** 지표 추가 기능을 시험하기 위해 일부러 남겨 둔 것이다.

## 카드 구성

```text
지표명
최신값 + 단위
상세보기 >
```

## 사용자 동작

카드를 누르면 상세 화면으로 이동한다.

```text
/indicator/base-rate
/indicator/cpi
/indicator/gdp
```

## 화면 구조

```text

| 기준금리                                              |
+-------------------------------------------------------+

현재값

---------------------------------------------------------

최근 데이터
2026-10     3.00

---------------------------------------------------------

---------------------------------------------------------

```

> 화면의 값과 날짜는 예시다. 실제 수집값이 아니다.

## 제공 기능

- 현재값
- 시계열 차트 (기간은 관리자 설정)
- 최근 데이터 표
- 출처, 통계 코드, 주기
- 마지막 수집 일시 (하루 1회 수집 기준)
- 관련 지표 (관리자 설정)

## KODEX 레버리지·인버스 안내 문구


## 제외 기능

- 지표 비교
- AI 분석, AI 요약

# 5. 관리자 화면 - Dashboard 관리

## 목적

메인 화면 구성과 지표별 설정을 관리한다.

## 화면 구조

```text
+-------------------------------------------------------+
| Dashboard Configuration                               |
+-------------------------------------------------------+

메인 화면 노출 지표                          [ 지표 추가 ]

순서   사용   지표명          주기   차트 기간   설정
-------------------------------------------------------
1      ON     기준금리        M      10년        [ 편집 ]
2      ON     고용률          M      10년        [ 편집 ]
3      ON     총인구          A      20년        [ 편집 ]
...
-------------------------------------------------------

[ 저장 ]
```

> 주기와 차트 기간은 예시다.

## 기능

| 기능 | 내용 |
| --- | --- |
| 노출 여부 | ON / OFF |
| 순서 | 메인 화면의 카드 순서 |
| 지표 추가 | 제공처, 통계 코드, 항목 코드를 넣어 새 지표를 만든다 |
| 수집 주기 | 지표마다 D / M / Q / A 중 선택 |
| 차트 기간 | 상세 화면 차트에 보여줄 기간 |
| 관련 지표 | 상세 화면 아래에 보일 지표 목록 |
| 표시 형식 | 숫자 자릿수, 소수점, 단위, 날짜 형식 |
| 저장 | DB에 저장하고 사용자 화면에 반영 |

# 6. 관리자 화면 - API 관리

## 목적

데이터 소스의 연결 상태를 확인하고, 수집 시간을 정한다.

API 키는 이 화면에서 입력·수정·표시하지 않는다. 키는 서버의 `.env`에서 소유자가 관리한다(KEDP001-D012).

## 화면 구조

```text
+-------------------------------------------------------+
| API Configuration                                     |
+-------------------------------------------------------+

수집 시간        매일 06:00   [ 변경 ]

-------------------------------------------------------
ECOS
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)

-------------------------------------------------------
KOSIS
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)

-------------------------------------------------------
공공데이터포털
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)
-------------------------------------------------------
```

## 기능

| 기능 | 내용 |
| --- | --- |
| 수집 시간 | 하루 1회 수집 시각 설정 (기본 06:00) |
| 연결 상태 | 연결 / 연결 안 됨 / 오류 |
| API 키 설정 여부 | 설정됨 / 설정 안 됨. `.env`에 키가 있는지만 표시하고, 키 값은 일부도 보여주지 않는다 |
| 마지막 수집 | 제공처별 마지막 수집 일시 |

## 향후 확장

- 연결 테스트
- 마지막 성공·실패 시간
- 재수집
- 수집 간격 줄이기 (1시간, 1분)

# MVP 범위

## 사용자

- 경제지표 대시보드
- 경제지표 상세 화면

## 관리자

- Dashboard 관리 (지표 설정 포함)
- API 관리 (상태, 수집 시간)

## MVP 제외 (2차 이후)

- 지표 비교
- AI 분석, AI Agent, 챗봇
- Claude API를 이용한 질문·수집·정리
- 검색, 추천, 상관관계 분석, 예측
- 화면에서 API 키 관리
