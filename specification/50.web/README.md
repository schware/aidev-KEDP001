# 1. 설계 원칙

## 사용자

사용자는 경제지표를 본다. 할 수 있는 것은 두 가지뿐이다.

- 현재 경제지표 확인
- 지표 상세 보기

검색 기능은 제공하지 않는다. 경제지표 수가 적어 첫 화면에서 모두 확인할 수 있게 설계한다.

## 관리자

관리자는 데이터와 화면 구성을 관리한다. 할 수 있는 것은 다음뿐이다.

- 메인 화면에 보일 지표와 순서
- 지표 설정 (추가, 수집 주기, 차트 기간, 관련 지표, 표시 형식)
- 수집 시간 설정
- API 연결 상태 확인 (키는 다루지 않는다)

관리자 설정은 DB에 저장한다.

## 관리자 접근

관리자 메뉴는 사용자 화면에 노출하지 않는다. 아래 3개 조건을 모두 만족해야 들어갈 수 있다.

- 지정 URL (`/admin`)
- 허용 IP
- 관리자 인증: 계정 + 비밀번호. 서버의 파일 하나로 관리한다. MVP에서는 더 발전시키지 않는다.

허용 IP, 계정, 비밀번호 같은 실제 값은 저장소에 쓰지 않는다.

# 2. 사용자 메인 화면

## 목적

현재 수집된 주요 경제지표를 한눈에 확인한다. 카드를 누르면 상세 화면으로 이동한다.

## 화면 구조

PC 폭(3열). 내용 폭은 정해져 있고 화면 가운데에 놓는다. 구분 하나는 카드 수만큼 칸을 쓴다(태블릿 2칸, PC 3칸까지). 카드가 적은 구분은 옆 구분과 한 줄에 놓여 오른쪽이 비지 않는다.

```text
+------------------------------------------------------------------+
| KEDP                                                             |
| Korea Economic Data Platform                                     |
+------------------------------------------------------------------+

                    대한민국 주요 경제지표

고용·소득            금리·통화
-------------------  -------------------
+-----------------+  +-----------------+
| 고용률          |  | 기준금리        |
| 62.8 %          |  | 3.00 연%        |
| 2026-09 기준    |  | 2026-09 기준    |
| 전월 대비 ▲0.2%p|  | 전월 대비 -     |
| 상세보기 >      |  | 상세보기 >      |
+-----------------+  +-----------------+

인구
----------------------------------------
+-----------------+  +-----------------+
| 총인구          |  | 출생아수        |
| 51,700,000 명   |  | 최신값          |
| 2025 기준       |  | 2025 기준       |
| 전년 대비 ▼…   |  | 전년 대비 ▼…   |
| 상세보기 >      |  | 상세보기 >      |
+-----------------+  +-----------------+

금융시장
-------------------------------------------------------------------
+-----------------+  +-----------------+  +-----------------+
| KODEX200        |  | KODEX 레버리지  |  | KODEX 인버스    |
| 최신값          |  | 최신값          |  | 최신값          |
| 2026-10-29 기준 |  | 2026-10-29 기준 |  | 2026-10-29 기준 |
| 직전 대비 ▲…   |  | 직전 대비 ▲…   |  | 직전 대비 ▼…   |
| 상세보기 >      |  | 상세보기 >      |  | 상세보기 >      |
+-----------------+  +-----------------+  +-----------------+

------------------------------------------------------------------
        자료: 한국은행 ECOS, 통계청 KOSIS, 공공데이터포털
                  오늘 N명 · 전체 N명
```

- 열 수: 휴대폰 1열, 태블릿(640px 이상) 2열, PC(1024px 이상) 3열.
- 맨 아래에 자료 출처를 늘 보인다. 방문자 수(40.api 6장)는 그 아래이고, 읽지 못하면 숫자만 보이지 않는다.

> 카드의 숫자는 화면 모양을 보여주기 위한 예시값이다. 실제 수집값이 아니다. 그림은 지금 등록된 지표 7개다.

## 구분별 묶기 (KEDP001-D024)

- 구분 이름(제목) 아래에 그 구분의 카드를 놓는다.
- 순서는 API가 준 순서(구분 순서 → 노출 순서) 그대로다. 화면에서 다시 정렬하지 않는다(`specification/40.api/README.md` 2장).
- 노출된 지표가 없는 구분은 제목도 보이지 않는다(그림에는 성장·경기, 물가, 부채·금융안정, 대외경제, 주택이 없다).
- 탭, 구분 이동 메뉴, 검색은 넣지 않는다.

## 처음 보이는 지표

처음 계획은 10개(그림의 7개 + CPI, GDP, 외환보유액)다. CPI, GDP, 외환보유액은 항목 코드를 확인하지 못해 아직 넣지 않았다(`b-go-end/config/indicators.yaml`). KOSPI, KOSPI200, 전산업 사업체 수, 채권, 국민소득 등은 처음 화면에 넣지 않고, **관리자 화면의 지표 추가 기능으로 넣는다.** 지표 추가 기능을 시험하기 위해 일부러 남겨 둔 것이다.

## 카드 구성

```text
지표명
최신값(크게) 단위
기준 시점(예: 2026-09 기준)
증감 한 줄(예: 전월 대비 ▲0.20%p, 전년 대비 ▼150,000 명)
상세보기 >
```

- 증감은 API의 `previous`, `change`를 그대로 쓴다(`specification/40.api/README.md` 2.1). 화면에서 다시 빼지 않는다.
- 이름은 주기마다 다르다: 전월 대비(M), 전기 대비(Q), 전년 대비(A), 직전 대비(D).
- 오르면 빨강 ▲, 내리면 파랑 ▼, 같으면 회색 `-`. 지표의 소수 자릿수로 0이 되면 같은 것으로 본다.
- 숫자는 그 지표의 소수 자릿수와 단위를 따른다.
- 단위가 `%`로 끝나면(`%`, `연%` 등) 증감 뒤 단위는 `%p`다(예: 전월 대비 ▼0.1%p). 비율 변화가 아니라 차이이기 때문이다. 그 밖의 단위는 지표 단위 그대로이고, 단위가 없으면 숫자만이다. 현재값과 최근 데이터 표의 단위는 바꾸지 않는다. 메인 카드와 상세 화면이 같다.
- `previous`가 `null`이면 증감 줄을 보이지 않는다.
- 카드 높이는 같은 줄에서 같다. 마우스를 올리면 테두리가 파래지고 조금 떠오른다.

## 사용자 동작

카드를 누르면 상세 화면으로 이동한다.

```text
/indicator/base-rate
/indicator/cpi
/indicator/gdp
```

# 3. 지표 상세 화면

## 화면 구조

```text
← 뒤로가기

금리·통화
기준금리

+-------------------------------------------------------+
| 현재값                                                |
| 3.00 연%                                              |
| 2026-09 기준                                          |
| 전월 대비 ▼0.25%p                                     |
+-------------------------------------------------------+

+-------------------------------------------------------+
| 추이                                                  |
| [ ECharts 시계열 차트 ]                               |
+-------------------------------------------------------+

+--------------------------+  +--------------------------+
| 최근 데이터              |  | 지표 정보                |
| 기간           값 (연%)  |  | 구분            금리·통화|
| 2026-09           3.00   |  | 출처                 ECOS|
| 2026-08           3.25   |  | 통계 코드         722Y001|
| 2026-07           3.25   |  | 주기                 월간|
|                          |  | 마지막 수집 2026-10-25 06:00|
|                          |  +--------------------------+
|                          |  +--------------------------+
|                          |  | 관련 지표                |
|                          |  | 소비자물가지수 >         |
+--------------------------+  +--------------------------+

[ 뒤로가기 ]
```

- 뒤로가기는 위쪽(작은 글 단추)과 아래쪽에 둔다.
- 현재값 아래 증감 표시는 2장 카드 구성과 같다.
- 최근 데이터와 지표 정보는 태블릿 폭(768px) 이상에서 나란히, 그보다 좁으면 위아래로 놓는다. 최근 데이터 표는 그 칸의 폭을 다 쓴다.

> 화면의 값과 날짜는 예시다. 실제 수집값이 아니다.

## 제공 기능

- 현재값
- 시계열 차트 (기간은 관리자 설정)
- 최근 데이터 표
- 출처, 통계 코드, 주기
- 마지막 수집 일시 (하루 1회 수집 기준)
- 관련 지표 (관리자 설정)

## KODEX 레버리지·인버스 안내 문구


# 5. 관리자 화면 - Dashboard 관리

## 목적

메인 화면 구성과 지표별 설정을 관리한다.

## 화면 구조

```text
+-------------------------------------------------------+
| Dashboard Configuration                               |
+-------------------------------------------------------+

메인 화면 노출 지표                          [ 지표 추가 ]

순서   사용   지표명          구분        주기   차트 기간   설정
---------------------------------------------------------------------
1      ON     기준금리        금리·통화   M      10년        [ 편집 ]
2      ON     고용률          고용·소득   M      10년        [ 편집 ]
3      ON     총인구          인구        A      20년        [ 편집 ]
...
---------------------------------------------------------------------

[ 저장 ]
```

> 주기와 차트 기간은 예시다. 순서는 구분과 상관없는 전체 순서다. 메인 화면은 구분으로 먼저 묶은 뒤 이 순서를 쓴다.

## 기능

| 기능 | 내용 |
| --- | --- |
| 노출 여부 | ON / OFF |
| 순서 | 메인 화면의 카드 순서(같은 구분 안에서의 순서가 된다) |
| 구분 | 지표마다 하나. 추가·편집 창에서 꼭 고른다. 목록은 `GET /api/admin/categories`(9개, migration으로만 바뀐다) |
| 지표 추가 | 제공처, 통계 코드, 항목 코드를 넣어 새 지표를 만든다 |
| 수집 주기 | 지표마다 D / M / Q / A 중 선택 |
| 차트 기간 | 상세 화면 차트에 보여줄 기간 |
| 관련 지표 | 상세 화면 아래에 보일 지표 목록 |
| 표시 형식 | 숫자 자릿수, 소수점, 단위, 날짜 형식 |
| 저장 | DB에 저장하고 사용자 화면에 반영 |

# 6. 관리자 화면 - API 관리

## 목적

데이터 소스의 연결 상태를 확인하고, 수집 시간을 정한다.

API 키는 이 화면에서 입력·수정·표시하지 않는다. 키는 서버의 `.env`에서 소유자가 관리한다(KEDP001-D012).

## 화면 구조

```text
+-------------------------------------------------------+
| API Configuration                                     |
+-------------------------------------------------------+

수집 시간        매일 06:00   [ 변경 ]

-------------------------------------------------------
ECOS
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)

-------------------------------------------------------
KOSIS
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)

-------------------------------------------------------
공공데이터포털
상태          ● 연결
API 키        설정됨 (.env)
마지막 수집   2026-10-25 06:00 (예시)
-------------------------------------------------------
```

## 기능

| 기능 | 내용 |
| --- | --- |
| 수집 시간 | 하루 1회 수집 시각 설정 (기본 06:00) |
| 연결 상태 | 연결 / 연결 안 됨 / 오류 |
| API 키 설정 여부 | 설정됨 / 설정 안 됨. `.env`에 키가 있는지만 표시하고, 키 값은 일부도 보여주지 않는다 |
| 마지막 수집 | 제공처별 마지막 수집 일시 |

## 향후 확장

- 연결 테스트
- 마지막 성공·실패 시간
- 재수집
- 수집 간격 줄이기 (1시간, 1분)

# KEDP MVP 철학

```text
먼저 수집한다.
먼저 저장한다.
먼저 보여준다.
해석은 그 다음 단계다.
```
