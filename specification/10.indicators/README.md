## 샘플 관리

- 지표별 실제 정상 응답 하나를 우선 확보한다.
- 오류 응답은 API별로 실제 확인됐을 때 추가한다.
- 결측·수정·단위 변경은 실제 발견 시 기록한다.
- 합성 샘플은 `synthetic-` 접두어와 생성 이유를 표시한다.
